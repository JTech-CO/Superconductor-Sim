# Superconductor Sim - 모델 수식과 적용 범위

이 문서는 브라우저 빌드가 실제로 사용하는 수식을 정리한다. 모든 초전도체가 모든 온도·자기장·주파수·형상·시료 이력에서 아래 식을 따른다고 주장하는 문서가 아니다.

## 1. 온도 의존 길이척도

앱은 `T < Tc`에서 다음 현상론적 보간식을 사용한다.

```text
lambda(T) = lambda_ref / sqrt(1 - (T/Tc)^4)
xi(T)     = xi_ref     / sqrt(1 - (T/Tc)^2)
```

브라우저 시연을 위한 명시적 보간법이다. 시료 보정 시에는 실측한 텐서형 `lambda(T)`, `xi(T)` 함수로 교체하는 것이 바람직하다.

## 2. GL 파생 임계장

```text
kappa = lambda / xi
Bc2   = Phi0 / (2*pi*xi^2)
Bc    = Phi0 / (2*sqrt(2)*pi*lambda*xi)
Bc1   ≈ Phi0/(4*pi*lambda^2) * (ln(kappa) + 0.5)
```

`Bc1`은 London/GL 근사이며 제1종/제2종 경계 근처에서 정확도가 낮다. 앱은 `1/sqrt(2)` 부근을 별도 `borderline`으로 표시한다.

## 3. 마이스너 슬랩

표면과 평행한 자기장을 받는 균일 슬랩 반두께 `a`에 대해

```text
B(x) = Bapp * cosh(x/lambda) / cosh(a/lambda)
```

를 계산한다. 임의 형상의 정밀 반자장 해가 아니다.

## 4. Bean 임계상태

혼합상 이력 렌더러는 1차원 반슬랩 자기장 분포를 저장하고

```text
|dB/dx| <= mu0 * Jc
```

조건을 만족하도록 표면 자기장 변화가 요구하는 최소한의 내부 분포를 갱신한다. 기본적인 자속 침투와 잔류 자속을 재현하지만 자속 크리프, 국소 텐서 구성식, 임의 3차원 형상, 완전한 Maxwell 결합은 포함하지 않는다.

앱의 슬랩 규약에서 자화는

```text
M ≈ (<B> - Bapp) / mu0
```

로 근사한다.

## 5. 현상론적 임계전류

```text
t = T/Tc
epsilon(theta) = sqrt(cos(theta)^2 + sin(theta)^2/gamma^2)
Beff = |B| * epsilon(theta)
Jc = Jc0 * max(0, 1 - t^2)^p / (1 + (Beff/B0)^q)
```

`p`, `q`, `B0`, `gamma`는 모델 파라미터다. 실제 정량 계산에는 실측 `Jc(T,B,theta,strain,history)` 또는 정당화된 피팅 곡면으로 교체해야 한다.

## 6. E-J 멱법칙

```text
E = Ec * (|J|/Jc)^n * sign(J)
```

기본 `Ec = 1e-4 V/m = 1 µV/cm`다. 실험과 비교하려면 해당 실험의 판정 기준과 맞춰야 한다.

## 7. 보텍스

평균 내부 자기장에 대해

```text
n_v = |<B>| / Phi0
atri = sqrt(2 / (sqrt(3) * n_v))
```

로 이상적인 삼각 보텍스 격자의 간격을 계산한다. 화면의 코어 광원은 그래픽 표현이며 Abrikosov/TDGL 질서변수 해나 실제 피닝 지도가 아니다.

## 8. 전기열 모델

단위길이 기준 집중정수 열수지는

```text
C' dT/dt = E*I - h*P*(T - Tbath)
```

형태다. `C'`는 초전도층과 구리의 단위길이 열용량 합이며 `P`는 외부 둘레다.

전류는 초전도층과 Cu 안정화층 사이의 병렬 전류식을 풀어 분배한다. `Tc` 아래에서는 초전도층에 멱법칙을, `Tc` 이상에서는 사용자가 지정한 정상상태 저항률을 사용한다.

### NIST 구리

RRR100 OFHC Cu에 대해 NIST 공개 열전도율 rational fit과 비열 log-polynomial fit을 `4–300 K` 범위에서 구현했다. 원 연구 저장소의 검증값 `k(77 K) ≈ 547.199698 W/(m K)`를 자동시험으로 확인한다.

구리 저항률은 NIST 저항률 피팅이 아니다. 앱은 Sommerfeld Lorenz 수를 사용한

```text
rho_Cu ≈ L0*T/k_Cu
```

근사로 도출한다. 자기저항과 이상 Wiedemann–Franz 관계에서의 편차는 포함하지 않는다.

## 9. 결합 보조 계산

원 연구 문서의 단순화 식을 다음처럼 구현한다.

```text
Tc ≈ omega_log/1.2 * exp[-1.04(1+lambda_epc) /
     (lambda_epc - mu*(1 + 0.62*lambda_epc))]
```

완전한 Allen–Dynes 식의 강결합·스펙트럼 형상 보정 인자는 생략한다. 비전통·강상관 초전도체에 보편식처럼 적용해서는 안 된다.

약결합 기준 갭은

```text
Delta0 = 1.764 kB Tc
```

이며 실측 갭으로 표시하지 않는다.

## 10. TDGL 경계

현재 앱은 완전한 TDGL을 풀지 않는다. pyTDGL 문서는 일반화된 2차원 박막 모델에서 막 두께가 특성 길이보다 작아야 하고, 엄밀한 이론적 기반은 `Tc` 근방 및 dirty 영역이라는 중요한 조건을 명시한다. 후속 TDGL 백엔드가 추가될 경우 이런 조건을 UI에 노출해야 한다.

## 11. 화학 모델

원 연구에서는 산소 민감 재료에 대해

```text
dc/dt = div(D grad c) + R(c,T,pO2)
```

형태의 별도 확산·반응 모델을 후보로 제안한다. 현재 저장소에는 보정 완료 확산계수·반응속도 상수가 없으므로, 이 브라우저 버전은 임의 상수를 만들어 화학 시뮬레이터처럼 표시하지 않는다.
